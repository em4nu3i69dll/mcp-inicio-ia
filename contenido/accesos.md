# Accesos de ejemplo

Los agentes consultan el MCP mediante stdio local o por SSH.
Cada integración remota utiliza una cuenta sin privilegios administrativos.
Los datos importados se revisan antes de actualizar el índice.
No se indexan archivos de entorno, claves privadas, certificados ni sesiones.
El MCP no ofrece terminal, SQL libre ni escritura de documentos.
Las notas se agregan manualmente desde el comando nota.
